# coopdx-updater
Really simple launcher / updater for sm64coopdx. Currently only works on Windows.

Meant for sm64coopdx v1.5+

This is an earlier prototype of the main coopdx-updater branch (core) that has a WinForms UI. I would have worked on this one more but I sacrificed a graphical user interface for cross platform support on the newer .NET runtime.
