# coopdx-updater

Automatic updater / launcher for sm64coopdx. Comes bundled with the game by default starting with v1.5

Requires [.NET Runtime 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

Has support for Windows, Linux, and macOS.

This application serves as a launcher and automatic updater for sm64coopdx. If no update is available, the launcher won't show a window and will just start sm64coopdx (which has to be in the same directory.)
If there is an update, it will download it, install it, and then run the game.

Starting with v1.5 the updater comes bundled with the game so you don't really have to worry about this page or download anything from here unless it says to do so
